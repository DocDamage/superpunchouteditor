# Community Tester Milestone Scope

The community tester milestone changes presentation, onboarding, test reporting, and tester-package automation. It does not replace the canonical ROM materialization architecture or production signing gates.

No ROMs, emulator binaries, private signing material, or signing credentials belong in this milestone.

The tester smoke path also covers the boxer graphics distinction: **Assembled Pose Preview** must show a complete in-game pose, while **Raw Tile Banks** is an explicitly labeled individual-8×8-tile reference view and may appear chopped by design.
