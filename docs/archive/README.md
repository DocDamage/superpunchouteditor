# Documentation Archive

The current project roadmap is [`../plans/PROJECT_REMEDIATION_AND_MODERNIZATION_PLAN.md`](../plans/PROJECT_REMEDIATION_AND_MODERNIZATION_PLAN.md).

`legacy-project-documentation-2026-08-18.zip` preserves 22 historical documents that were removed from the live documentation tree on 2026-08-18. The archive contains:

- eight implementation snapshots from `docs/implementation/`;
- eight superseded plans and feature specifications from `docs/plans/`; and
- six historical V4/V5 architecture proposals from `docs/proposals_v4_v5/`.

The paths inside the ZIP match their original repository-relative paths. The files can therefore be reviewed or restored without guessing where they came from.

Documentation retained outside the archive is still operationally useful: build and contributor guidance, in-app help compiled by the Rust backend, current component/configuration guides, plugin documentation, community data guidance, ROM research, and the authoritative remediation roadmap.
