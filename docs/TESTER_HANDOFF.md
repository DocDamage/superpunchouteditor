# Tester Handoff

Share the generated **community tester kit ZIP** with Windows testers.

Testers should:

1. Extract the ZIP.
2. Read `START_HERE.md`.
3. Verify the installer hash against `CHECKSUMS.txt`.
4. Install the test build.
5. Supply their own legally obtained Super Punch-Out!! ROM locally.
6. Follow the guided editor workflow.
7. Open **Tester Checklist** in the app.
8. Copy or download the generated Markdown report and return it to the project owner, or use the repository's **Community test report** issue template.

Do not request or accept ROM files, SRAM/save states, extracted commercial game data, emulator binaries, private signing keys, certificates, or passwords from testers.
